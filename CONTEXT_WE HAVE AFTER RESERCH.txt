1. PROJECT IN ONE SENTENCE
============================================================

Orbis is a Space Situational Awareness prototype that
uses real orbital data, orbital mechanics, conjunction
analysis, machine learning, and uncertainty modelling to
identify and assess potential collision risks between
important active satellites and space debris.


============================================================
2. WHAT PROBLEM ARE WE ACTUALLY SOLVING?
============================================================

Earth orbit contains many artificial objects:

â€¢ Active satellites
â€¢ Inactive/defunct satellites
â€¢ Rocket bodies
â€¢ Fragmentation debris
â€¢ Other tracked orbital objects

All these objects move at very high orbital velocities.

If two objects approach each other closely, there is a
possibility of collision.

The problem is NOT simply:

"Where is the satellite?"

The actual problem is:

"Where will the satellite and debris be in the future,
will their trajectories bring them close to each other,
when will the closest approach happen, how close will
they come, and how should the risk of that encounter
be assessed?"

That is the problem Orbis tries to address.

7. WHAT IS TLE DATA?
============================================================

TLE means:

Two-Line Element Set.

A TLE is a standard representation of orbital information
associated with an orbital object.

It does NOT directly mean:

Latitude = X
Longitude = Y

Instead, it contains orbital information that can be
propagated to obtain an object's state at a requested time.

Conceptually:

 â†“

19. WHY DON'T WE COMPARE EVERY OBJECT WITH EVERY OTHER
OBJECT DIRECTLY?
============================================================

If the catalogue contains many objects, comparing every
possible pair can become computationally expensive.

Conceptually, if there are N objects, the number of pairs
can grow approximately as:

Therefore we need efficient screening.

Orbis proposes:

Step 1:
Remove obviously unrelated objects.

Step 2:
Perform detailed TCA / miss-distance calculations only
for plausible candidates.

24. RELATIVE MOTION
============================================================

For two objects:

Object A position = rA
Object B position = rB

Relative position:

rRel = rA - rB

Similarly, we can determine relative velocity:

vRel = vA - vB

These relative quantities help us understand how the two
objects are approaching each other.

This becomes important for:

â€¢ TCA
â€¢ Miss distance
â€¢ Collision-risk features

30. WHY MONTE CARLO?
============================================================

No orbital prediction is perfectly certain.

There can be uncertainty in:

â€¢ Orbital state
â€¢ TLE information
â€¢ Propagation
â€¢ Measurement/tracking
â€¢ Object characteristics

Monte Carlo simulation can help us model this uncertainty.

Basic idea:

1. Start with estimated orbital state.
2. Generate many plausible variations.
3. Propagate those samples.
4. Calculate conjunction outcomes.
5. Observe how the risk changes.


============================================================
31. SIMPLE MONTE CARLO EXAMPLE
============================================================

Suppose the estimated miss distance is:

2.0 km

But the orbital state has uncertainty.

Instead of assuming exactly 2.0 km, we simulate many
possible states:

1.8 km
2.1 km
1.6 km
2.4 km
1.9 km
...

After many simulations we can examine the distribution
of possible outcomes.

That gives us a better understanding of uncertainty.


============================================================
32. WHY UNCERTAINTY MATTERS
============================================================

Suppose a single deterministic calculation says:

"Miss distance = 2.0 km"

That sounds exact.

But the real question is:

"How confident are we in that estimate?"

Monte Carlo helps us answer that.

Therefore our project is not simply:

distance calculation

It aims to consider:

distance + uncertainty

72. FINAL PROJECT STORY
============================================================

The complete story we tell is:

Earth orbit is becoming more congested.

We need to know where orbital objects will be.

TLE gives us orbital information.

SGP4 propagates the objects into the future.

Conjunction analysis identifies potentially close
encounters.

TCA tells us when the closest approach occurs.

Miss distance tells us how close the objects become.

Additional orbital/event features describe the encounter.

XGBoost is used as the proposed ML risk-assessment layer.

Monte Carlo examines uncertainty.

The dashboard presents the result to a human operator.

Therefore Orbis connects:

DATA
+
PHYSICS
+
AI
+
UNCERTAINTY
+
VISUALIZATION

into one end-to-end prototype.
